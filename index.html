    How to Play

    Generate

    Tap a station (round base with a glowing item) to produce a tier-1 ingredient on a free cell.

    Merge

    Select an item, then select an identical item to merge them into the next tier. Chains run from tier 1 up to tier 5.

    Serve

    When a dish matches a customer order, select it and press Serve before the order expires. Quick consecutive serves build a streak bonus.

    Efficiency

    Empty board cells at round end add an efficiency bonus. Discard clutter with Discard.

    Controls

    Pointer or touch: tap to select, tap target to act. Keyboard: arrow keys move focus, Enter selects, S serves, D discards, U undoes (practice), H hints, Esc pauses, C resets the camera.
